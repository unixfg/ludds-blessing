# Ludd’s Blessing 0.1.6 community beta

This hotfix corrects the save-library regression introduced by broader Windows
save discovery in 0.1.5.

Highlights:

- Legacy format-0.5 descriptors that omit `gameVersion` and
  `slotCreationTimestamp` now retain their character, level, date, format, and
  other available metadata instead of appearing as unreadable saves.
- Missing legacy metadata does not weaken write authorization. Only the exact
  supported RC8/format-0.6 descriptor shape receives editing capabilities, and
  incomplete RC8 descriptors fail closed as read-only.
- Current and usable saves now sort ahead of unreadable archive entries.
  Unknown or missing dates no longer sort above real timestamps.
- The two legacy folders that exposed the regression were exercised read-only,
  along with a current RC8 fixture. The uncompressed legacy save also completes
  the semantic preview path.

All processing remains local. No save fixture is bundled, committed, or
modified. The app has no telemetry, network feature, updater, bundled
Starsector assets, or required Starsector mod.

This build is unsigned. Verify the SHA-256 manifest before use and expect a
Windows SmartScreen warning. Prefer **Save a Copy** while testing beta builds.
