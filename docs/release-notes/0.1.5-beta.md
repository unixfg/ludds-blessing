# Ludd’s Blessing 0.1.5 community beta

This beta broadens save discovery while keeping catalog loading and live-game
write protection tied to the same verified Starsector installation.

Highlights:

- Verified Windows installations now use the save folder configured by RC8's
  `vmparams`, including custom absolute locations, instead of assuming every
  save lives under the installation directory.
- Installation discovery checks both registry views, current-user and machine
  uninstall records, standard Program Files locations, and bounded Documents
  locations that can contain a complete custom installation.
- Standalone save discovery checks Windows Known Documents, traditional and
  OneDrive Documents paths, and narrowly matched legacy VirtualStore paths.
- **Refresh** repeats automatic discovery, and one unavailable candidate no
  longer prevents healthy save roots from being shown.
- Manually selected installations, save roots, save directories, and save XML
  files remain supported. No drive-wide or home-directory crawl was added.
- Local skills, portraits, factions, items, and ships are now loaded only from
  a uniquely verified installation associated with that save root. Standalone
  archives cannot accidentally inherit catalogs from an unrelated parent
  directory.
- The running-game guard resolves the same configured save root before allowing
  writes to a different inactive save. Unreadable or ambiguous configuration
  fails closed; legacy VirtualStore saves stay write-locked while the game runs.
- Existing `roots.json` files are migrated automatically to retain verified
  installation associations without invalidating previously remembered roots.

All processing remains local. The app has no telemetry, network feature,
updater, bundled Starsector assets, or required Starsector mod.

This build is unsigned. Verify the SHA-256 manifest before use and expect a
Windows SmartScreen warning. Prefer **Save a Copy** while testing beta builds.
