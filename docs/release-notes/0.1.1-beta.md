# Ludd’s Blessing 0.1.1 community beta

Binary-only Windows 10/11 x64 beta of the local-first Starsector save editor.

Highlights:

- Guarded write support for uncompressed `0.98a-RC8` / save format `0.6` only.
- Semantic character, reputation, officer, cargo, and colony-stockpile editing
  with immutable review.
- Direct, catalog-authorized additions for colony Storage commodities, weapons,
  fighter LPCs, and individual blueprints, plus economic commodities in Local
  Resources.
- Byte-span patching, external backups, hash-bound transactions, rollback, and
  recovery state.
- No telemetry, network feature, updater, or bundled Starsector assets.
- No installed, generated, or required Starsector mod.

This build is unsigned. Verify the SHA-256 manifest before use and expect a
Windows SmartScreen warning. Review the included beta guide and test edited
copies in-game before relying on them.
