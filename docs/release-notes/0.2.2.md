# Ludd’s Blessing 0.2.2

Version 0.2.2 makes the save library and open editor distinct contexts and
automatically refreshes discovery before loading a selected campaign. The
strict uncompressed Starsector `0.98a-RC8` / save-format `0.6` write gate is
unchanged.

## Highlights

- The Saves library no longer shows Character through Review alongside it.
  Opening a campaign switches to dedicated editor navigation, while **Close
  editor** safely returns to the library.
- **Open editor** and **Open preview** repeat bounded discovery immediately
  before loading. If a listed save disappeared or became unreadable, the
  library is updated and the stale entry is not opened.
- A successful **Create backup & apply** or **Save a copy** closes the editing
  session, refreshes the library, and returns to Saves instead of leaving the
  completed campaign open.
- Closing an editor with staged changes or a pending review still requires
  explicit confirmation. Read-only saves now open directly in the dedicated
  preview/editor context.

## Distribution

- The Windows release is one standalone executable with no installer or
  updater. It uses an already installed Microsoft WebView2 Evergreen Runtime
  and does not download one.
- A stable version tag builds and publishes the Windows executable
  automatically. GitHub also provides the corresponding tagged source
  archives.

This release is unsigned. Windows SmartScreen may warn before launch. Verify
the executable against the SHA-256 digest shown by GitHub, retain Starsector’s
own backups, and use Save Copy for the first test of any important campaign.
