# Ludd’s Blessing 0.2.3

Version 0.2.3 remembers reviewed warnings for each save, so unchanged warnings
no longer interrupt later saves.

## Highlights

- Acknowledging a warning carries through rebuilt reviews and unrelated edits.
  After a successful **Create backup & apply** or **Save a copy**, the app
  remembers those acknowledgments across restarts.
- Previously reviewed warnings remain visible. New warnings or changes to the
  values that caused them require acknowledgment again, even when their text
  stays the same.
- Warning history is specific to each save. Copies inherit reviewed conditions,
  and identifiable officers retain their history when the roster is reordered.
- Restore and interrupted-write recovery still require confirmation each time.
  Validation errors continue to block saving.

## Local storage

Warning history is stored in the app's user-data directory as
`reviewed-warnings-v1.json`. On Windows, this is
`%APPDATA%\app.ludds-blessing.editor\reviewed-warnings-v1.json`.

## Distribution

Download `LuddsBlessing_0.2.3_windows-x64.exe` for Windows 10/11 x64. This is a
standalone executable with no installer or updater and requires an already
installed Microsoft WebView2 Evergreen Runtime. GitHub also provides the
tagged source archives.

The executable is unsigned. Windows SmartScreen may warn before launch.
