# Ludd’s Blessing 0.1.4 community beta

This beta improves how continuous resource quantities are presented.

Highlights:

- Saved resource quantities now hide harmless single-precision float noise
  while their fields are at rest; for example, `721.32007` is shown as
  `721.32`.
- Focusing a quantity field restores its exact saved value before editing.
- Display formatting never creates a staged edit and never changes save bytes.
- Tiny positive quantities that would round to zero remain displayed exactly.
- Review continues to show exact old and new values so even a one-float-step
  change remains visible before apply.

The underlying value reported in the affected Local Resources stockpile is a
valid Starsector/Java single-precision value, not a malformed stack. Resource
quantities remain continuous values; crew is not coerced to a whole number.

All processing remains local. The app has no telemetry, network feature,
updater, bundled Starsector assets, or required Starsector mod.

This build is unsigned. Verify the SHA-256 manifest before use and expect a
Windows SmartScreen warning. Prefer **Save a Copy** while testing beta builds.
