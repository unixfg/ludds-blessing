# Ludd’s Blessing 0.1.2 community beta

Hotfix release for newly started Starsector campaigns.

Fixes:

- Opens valid RC8 saves where Starsector omits the authoritative officer-roster
  container because the player has no officers yet.
- Continues to reject duplicate officer rosters and malformed populated roster
  entries instead of guessing at save structure.

All save processing remains local. This build has no telemetry, network feature,
updater, bundled Starsector assets, or required Starsector mod.

This build is unsigned. Verify the SHA-256 manifest before use and expect a
Windows SmartScreen warning. Prefer **Save a Copy** while testing beta builds.
