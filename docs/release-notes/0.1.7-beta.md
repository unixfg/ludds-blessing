# Ludd’s Blessing 0.1.7 community beta

This usability update makes officer skill editing faster while keeping the
selected officer within reach during long ability lists.

Highlights:

- Every officer now has **Make all Unlearned**, **Make all Learned**, and
  **Make all Elite** controls.
- Bulk controls affect only recognized, editable skills. Unknown or malformed
  mod skills remain read-only, and each requested rank is capped at the
  individual skill's supported maximum.
- Repeated bulk choices reconcile with the saved ranks, so the semantic review
  contains only actual changes and previously staged ranks are cleared when
  they return to their original values.
- The desktop officer roster is sticky with bounded independent scrolling. At
  compact widths it becomes a sticky horizontal roster above the officer
  detail, preserving access at high zoom and on smaller windows.
- Automated UI coverage verifies all three bulk transitions and read-only skill
  preservation. A production browser pass verifies the roster remains visible
  after scrolling through the ability section at desktop and compact widths.

All processing remains local. No save fixture is bundled, committed, or
modified. The app has no telemetry, network feature, updater, bundled
Starsector assets, or required Starsector mod.

This build is unsigned. Verify the SHA-256 manifest before use and expect a
Windows SmartScreen warning. Prefer **Save a Copy** while testing beta builds.
