# Ludd’s Blessing 0.1.3 community beta

This beta adds target-specific game activity checks for Windows.

Highlights:

- Starsector may remain open while applying edits to a different, confirmed
  inactive save.
- Every save that may still be active in Starsector remains blocked from apply,
  restore, protected-save unlock, and recovery operations.
- The editor reads bounded local Starsector activity logs, including rotated
  logs, and fails closed if the active save cannot be identified reliably.
- Target-specific writes require one verified native Starsector instance.
  Multiple or otherwise unverifiable game processes remain blocked.
- Activity is rechecked throughout the transaction alongside existing locks,
  source hashes, durable backups, journals, reparsing, and semantic validation.
- The Review screen warns users not to load or switch to the target while a
  write is running.

All processing remains local. The app has no telemetry, network feature,
updater, bundled Starsector assets, or required Starsector mod.

This build is unsigned. Verify the SHA-256 manifest before use and expect a
Windows SmartScreen warning. Prefer **Save a Copy** while testing beta builds.
